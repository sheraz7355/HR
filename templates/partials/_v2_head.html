{# UI v2 opt-in for pages that render OUTSIDE templates/layouts/app_shell.html. The shell stamps `data-ui="v2"` on and links these stylesheets for every module in UI_V2_MODULES. A page with no shell — the landing page, the sign-in screens, the company portal, the module hub, the super admin console — inherits none of that and must repeat it (UI_V2_GUIDE.md §2). Missing it does not fall the page back to v1: every `--v2-*` name it reaches for becomes undefined, and an undefined custom property invalidates the whole declaration rather than inheriting, so the page loses its colours outright (§3). The caller still supplies `data-ui="v2"` on its own element — that is the attribute every rule in ui.css is scoped to, and it cannot be set from inside . Include this BEFORE the page's own
